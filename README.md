# 游戏库

这是一个个人小游戏合集，主要收录使用 HTML、CSS、JavaScript 和 MATLAB 制作或复现的经典游戏。

项目主要用于学习编程、界面设计和交互，同时也希望把这些独立制作的小项目整理成一个简单的个人游戏库。

## 游戏

目前包含：

- Snake
- Pac-Man
- Minesweeper
- Flappy Bird
- Tetris
- 2048
- Conway's Game of Life
- 其他实验性项目

游戏库会持续更新，并加入更多小游戏。

## 技术

项目主要使用：

- HTML
- CSS
- JavaScript
- MATLAB

网页版游戏可以直接在现代浏览器中运行，部分游戏针对电脑端和手机端进行了适配。

MATLAB 版本主要用于游戏复现、GUI 开发、动画和仿真。

## 关于

这是一个个人项目，主要用于学习、实践和记录。

通过复现一些熟悉的经典游戏，尝试不同的编程语言、开发方式和交互设计。

如果你喜欢其中的某个游戏，欢迎体验。

# Game Library

This is a personal collection of small games, mainly featuring classic games created or recreated with HTML, CSS, JavaScript, and MATLAB.

The project is mainly used for learning programming, interface design, and interaction, while also organizing these independently developed projects into a simple personal game library.

## Games

Currently included:

- Snake
- Pac-Man
- Minesweeper
- Flappy Bird
- Tetris
- 2048
- Conway's Game of Life
- Other experimental projects

The library will continue to be updated with more games.

## Technologies

The project mainly uses:

- HTML
- CSS
- JavaScript
- MATLAB

The web games can be played directly in modern browsers, with some games adapted for both desktop and mobile devices.

The MATLAB versions are mainly used for game recreation, GUI development, animation, and simulation.

## About

This is a personal project mainly created for learning, experimentation, and documentation.

By recreating familiar classic games, I explore different programming languages, development approaches, and interaction designs.

Feel free to try any of the games you find interesting.
